📝 Sistema de Boletim Escolar

Este é o meu primeiro mini-projeto criado durante a Maratona Java (DevDojo)! 🚀

🎯 Objetivo do Projeto

O objetivo deste pequeno sistema é calcular a média de um aluno com base em três notas de provas e, utilizando a lógica de programação, definir automaticamente se o aluno foi aprovado ou reprovado.

🛠️ Tecnologias e Conceitos Utilizados

Neste projeto, coloquei em prática os seguintes conceitos aprendidos nas aulas:

Tipos Primitivos: Utilização do tipo double para lidar com notas decimais e boolean para lógica de verdadeiro/falso.

Operadores Aritméticos: Cálculos matemáticos usando parênteses para garantir a ordem de precedência (soma antes da divisão).

Operadores Relacionais: Utilização do operador >= para verificar se a média atingiu o critério de aprovação.

Concatenação: Junção de variáveis e textos para gerar um relatório final dinâmico no console.

💻 Como o programa funciona

O sistema recebe as notas do aluno no próprio código, calcula a média dividindo a soma por 3, e testa se o valor é maior ou igual a 6.0. No final, ele imprime um relatório completo no console.
